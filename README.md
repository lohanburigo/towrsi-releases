# towr.si · downloads

Este repositório só guarda as versões do [towr.si](https://towr.si) para baixar e o feed de atualizações do app. O código não está aqui.

**[Baixar a última versão](https://github.com/lohanburigo/towrsi-releases/releases/latest/download/towr.si.dmg)** (beta grátis)

- macOS 15 ou mais novo, Apple Silicon ou Intel.
- O app roda as ferramentas que já estão no seu Mac: instale o Claude Code ou o Codex e entre com a sua conta neles.
- Assinado com Developer ID e notarizado pela Apple. Depois de instalado, o app avisa quando sai uma versão nova (menu do app → Procurar atualizações…).
